# Source-linked extraction specification

Reassess the candidate's eligibility against the eight conditions. Read the operative regulations, application documents and official programme materials directly. Extract the 75-variable instrument in `protocol/codebook_75.csv`. Retain the original-language passage, URL, access date and evidence note for each value; distinguish programme facts from independently sourced context.

Prefer direct statements. Use inference only when a transparent, labelled documentary chain supports the value. Code `No` only for an explicit exclusion or an authoritative closed list. Code `Not stated` when the accessible documents neither state the feature nor support defensible inference. Keep failed retrieval distinct from documentary silence. Keep programme identity, geography, responsible authority and operative period aligned with the passage.

Keep eligibility, technical support, payment timing, maintenance responsibility, maintenance support and monitoring as separate constructs. Evidence linkage is not proof of correct interpretation.

For independent human recoding, hide the original values. For the source-validation reviews, disclose programme identity, the coding rule and search instructions but hide the stored value; freeze both references before unmasking. Resolve disagreements against live sources and the governing rule. Store corrections separately. Shared-dossier rereview is source-harmonised repeatability, not independent inter-rater reliability.
